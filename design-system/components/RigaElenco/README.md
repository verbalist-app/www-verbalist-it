# RigaElenco

Una voce d'elenco sul cielo: glifo, nome a sinistra, descrizione a destra, filetto sotto.

Fornisci tu, per ogni riga, un glifo a blocchi, un nome di una-tre parole e una descrizione di due-quattro parole.

- Riga alta `space-140`; glifo da `space-40` sul margine; nome a `space-40` dal glifo.
- Nome in `lead` `on-sky`; descrizione in `lead` `on-sky-muted`, allineata a destra.
- Sotto ogni riga un filetto `rule-on-sky` largo quanto l'area utile.

- Sì: da tre a cinque righe; nome e descrizione sulla stessa riga.
- No: testo che va a capo; frecce o chevron; fondo o bordo attorno alla riga. Un elenco più lungo diventa un `Foglio`.
