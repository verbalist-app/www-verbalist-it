# Chip

Un'etichetta di una-tre parole sul foglio, per elencare ciò che una fase contiene.

Fornisci tu il testo.

- Fondo `chip`, testo `ink-muted` in `paper-chip`, `radius-chip`, rientro 2 × 8px.
- In colonna sotto la propria fase, a 12px l'uno dall'altro.

- Sì: solo informativi.
- No: chip cliccabili, colorati o con icona; chip sul cielo.
